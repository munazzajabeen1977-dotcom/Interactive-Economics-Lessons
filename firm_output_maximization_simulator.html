How to read it: the budget line shows every input combination the firm can afford. Each isoquant traces input combinations giving equal output — isoquants further from the origin mean more output. The firm reaches the highest possible isoquant it can afford at the point where it's exactly tangent to the budget line — that's where the marginal rate of technical substitution equals the input price ratio (w/r), the same tangency rule as cost minimization, just approached from the opposite direction.
